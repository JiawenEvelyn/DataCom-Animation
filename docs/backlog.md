### 用户故事（M1）

- **B-101**：作为学习者，我想自己控制每一步什么时候继续，这样我能看完每一步的文字说明。
  验收：播放后每一步动画结束就停住；点「下一步」或按 → 才继续；能回到任意一步；可以手动开启自动播放。
- **B-102**：作为学习者，我想看清报文在网络里长什么样、带了什么关键信息，这样我能对流量有结构化的认识。
  验收：每一步都能看到报文当前的分层结构（例如 以太 / IP / TCP / 数据）和每层关键字段；这一步改动的字段高亮并显示旧值和新值；封装和解封装时层的增减有动画。
