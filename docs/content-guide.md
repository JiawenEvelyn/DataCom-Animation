# 内容规范

> **这份文档是什么**：讲解、动画字幕、报文字段、命令示例这些「知识内容」怎么写、怎么找来源、怎么标注。
> **什么时候用**：写任何学习内容之前，以及评审内容时。

## 1. 范围

只讲**运营商 IP 网络**（骨干网、城域网、IP 承载网）。园区网、企业网、宽带接入、光传输、移动核心网不在范围内。详见产品规划书第六节。

## 2. 来源

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | 华为公开页面：产品页、Datasheet、华为百科（info.support.huawei.com/info-finder）、在线配置指南 | 设备参数、型号、命令风格以这里为准 |
| 2 | IETF RFC（rfc-editor.org、datatracker.ietf.org） | 协议字段、报文格式、状态机以 RFC 为准 |
| 3 | 公开的考试和竞赛大纲 | 只用来判断「该学什么」，不作为知识细节的来源 |

**访问规则（必须遵守）**：

- 只做正常的浏览访问。不绕过网站限制，不规避反爬、登录或机器人检查，不下载受限文档，也不请别人下载后转交。
- 打不开的页面如实说明，换一个能正常打开的公开页面。
- 来源链接登记到 `SRC` / `SRC_EN`，讲解条目里引用。

## 3. 准确性

- **不编造**：参数、型号、字段名、字段长度、默认值都要能对应到来源。查不到的标「示意」或「待确认」。
- **通用原理和设备实现分开**：「NP 查表」「TM 排队」是通用原理；「NetEngine 8000 X8 有 8 个业务槽位」是具体设备的事实。不要把通用原理说成某款设备的实现。
- **示例数值标示意**：IP 地址、MAC、端口、标签值这类示例数值，在画面或讲解里注明「示意」。
- **只列关键字段时要说明**：报文透视只展示和当前知识点相关的字段，面板上注明「只列关键字段」。

## 4. 语气

- 口语化、好懂，可以用比喻，但比喻之后要回到准确的术语。
- 不要照搬官方文档的长句。
- **只写客观知识**，不写带主观假设的话（例如「你开发的网管系统……」）。
- 术语第一次出现时中英文对照：「转发信息库（FIB，Forwarding Information Base）」。

## 5. 中英文

- 界面短文案：`L('中文','English')`。
- 讲解条目：`KB` 写中文，`KB_EN` 写英文；英文模式下副标题显示中文名，方便对照术语。
- 命令和设备回显保持英文原样，不翻译。
- 协议字典里的层名和字段名都要有中英文。

## 6. 一条讲解的结构

```
标题（中文 + 英文名）
一句话：它是什么、干什么用
要点：3～5 条，每条一个知识点
配置示例：可在模拟命令行运行的命令（如果有）
来源：链接
```
