# 0003 · 分步播放默认手动，状态可回放

- 状态：提议（在 spec 001 评审时一起确认）
- 日期：2026-11-06

## 背景

现在的流程动画每一步播完 1.5 秒后自动进入下一步，学习者来不及读完说明。另外现在的「上一步」只是重播那一步的动画，舞台上已出现的元素和表格状态不一定正确回退。

## 可选方案

### 方案 A：延长自动间隔

- 优点：改动最小。
- 缺点：读得快的人嫌慢，读得慢的人仍然不够；无法停下来对照报文字段。

### 方案 B：默认手动，自动播放可选

每一步动画播完就停住，等学习者点「下一步」（或按 →）。另外提供自动播放开关，间隔按说明文字长度计算。

- 优点：学习者掌控节奏，符合产品原则「学习者掌控节奏」；也方便插入「预测下一步」的小测验。
- 缺点：多点几下。

## 决定

选方案 B。同时把每一步的状态改成可计算的：第 N 步的状态 = 初始状态 + 前 N 步的操作，这样跳到任意一步、后退都能得到正确画面。

## 后果

- 步骤数据里不能依赖「上一步的动画副作用」，所有状态变化都要写成数据（显示元素、表项变化、报文操作）。
- 播放器要有：上一步 / 下一步 / 重播本步 / 步骤列表 / 自动播放开关。
- 测试可以直接跳到任意一步截图检查，不用等动画。
