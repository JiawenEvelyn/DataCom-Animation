# 0001 · 纯静态页面，无构建、无依赖

- 状态：已接受
- 日期：2026-10-31（补记于 2026-11-06）

## 背景

项目是个人学习工具，需要：随时用浏览器打开；能发布成 claude.ai Artifact 在线预览（单个 HTML 文件，外部脚本只能来自少数 CDN）；维护成本低。

## 可选方案

### 方案 A：纯静态 HTML + CSS + 原生 JS

- 优点：双击就能打开；没有构建步骤，也没有依赖要升级；打包成 Artifact 只需把 CSS 和 JS 内联。
- 缺点：没有模块系统和类型检查，代码变大后要靠约定来组织。

### 方案 B：前端框架（React / Vue）+ 构建工具

- 优点：组件化，生态成熟。
- 缺点：需要 Node 构建；依赖要维护；产物要另外处理才能变成单文件 Artifact。对现在的规模来说负担大于收益。

## 决定

选方案 A。项目规模和发布方式都更适合零构建。

## 后果

- 代码组织靠约定：`js/app.js` 按区块排列，见 [architecture.md](../architecture.md)。
- 文件变大后可以拆成多个 `<script>`，按顺序加载，仍然不需要构建。
- 自动测试依赖 Playwright（环境里已预装），只用于开发，不进入页面。
